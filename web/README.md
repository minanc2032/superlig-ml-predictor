# Süper Lig ML Predictor — web

Next.js frontend for the [Süper Lig ML Predictor](../README.md): a landing page, a sortable 2025/26 predictions dashboard, and an `/explore` stub. It reads a pre-generated JSON file at build time, so **no Python runs on Vercel**.

## Run locally

```bash
cd web
npm i
npm run dev      # http://localhost:3000
npm run build    # works offline — uses the committed predictions.json
```

## Deploy (Vercel)

Set the project **Root Directory to `web`**. No environment variables or Python runtime are needed.

## Data: `public/data/predictions.json`

Generated by the Python model from the repo root (with the project's venv active):

```bash
python scripts/export_predictions.py
```

A sample is committed so the site builds without Python. Shape (snake_case, mirrors the model's `predict_table()` columns):

```jsonc
{
  "meta": {
    "season": "2025/26", "teams": 18, "mae": 4.63,
    "seasons_used": 7, "trained_on": "2018/19-2024/25",
    "algorithm": "Random Forest Classifier", "generated_at": "<ISO 8601 UTC>"
  },
  "predictions": [
    {
      "predicted_rank": 1,            // model output
      "team": "Galatasaray",          // model output (display name)
      "expected_position": 2.51,      // model output
      "logo_slug": "galatasaray",     // asset lookup -> public/logos/<slug>.png
      "last_season_position": 1       // real 2024/25 finish, context only; null for promoted clubs
    }
  ]
}
```

Only `predicted_rank`, `team` and `expected_position` are model outputs. The site never shows invented next-season points, W/D/L or goals. `src/lib/predictions.ts` maps the snake_case JSON to camelCase types; `src/lib/zones.ts` derives the status badges (title race / Europe / safe / relegation) from rank in the UI — they are not model labels.

## Stack

Next.js 16 (App Router, static pages) · Tailwind CSS v4 (CSS-first tokens in `src/app/globals.css`, light + dark) · shadcn/ui `base-nova` on `@base-ui/react` · TanStack Table v9 · Recharts · GSAP (skipped under `prefers-reduced-motion`) · Lucide icons · Fira Sans / Fira Code.

Note: this is Next.js 16 and TanStack Table **v9**, whose APIs differ from v15 / v8 (`useTable`, `tableFeatures`, `table.FlexRender`). See `AGENTS.md` and `node_modules/@tanstack/react-table/skills/`.
